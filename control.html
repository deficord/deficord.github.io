⚡使用说明 · 怎么出片

方式一 · 网页一键出片（最省事）
双击 start_serve.bat → 自动开 http://localhost:8080/ → 选 类型/系列/集 → 点「开始出片」，实时看日志。
方式二 · 终端菜单
双击 start.bat → 输入数字选 类型→系列→集→模式，回车即出。
方式三 · 复制命令
双击 出片速查.html → ④集数索引搜到那集 → 点「复制出片」→ 粘终端回车。
方式四 · 公网指南
开 deficord.github.io/control.html：索引+复制命令（不自出片）。
改了再出片：改文案/分镜 → 浏览器开 storyboard.html 改字 → 重跑一键出片（覆盖）；只换素材 → 替换 out/.../footage/*.mp4 → 跑「只重合成」；只调封面 → studio_multiplat.html 改并下载 → 覆盖 covers/*.png → 跑「只重合成」。
只重合成命令：node render_final.js --dir out/<系列>_第N集

①集数索引（共 0 集）

#类型系列集标题操作
点「复制出片」把 node make_video.js --i N --covers --final 复制到剪贴板；粘贴到终端回车即出那集（即使在未连接模式的资料库/网站上也可用）。
