🎬 中文视频生成器 · OpenMontage 零成本

文案嵌入 · 音色 / 背景 / 语速自由选择 · 一键生成可在本机运行的脚本

① 填写文案

支持中文（建议 50–300 字），可从 GLUCK「运营思路题库」复制选题。用全角句号（。）分句，配音会自动按句停顿。

② 选择样式

三个下拉自由组合。全部零成本中文优化方案。点「生成」会在下面得到一段可在本机一键运行的 Python 脚本。

③ 生成的脚本

把脚本保存到本机 OpenMontage 目录下，运行 python make_cn_video.py，即可在 projects/demos/cn_out/ 获得 mp3 配音 + 9:16 竖屏 mp4 视频。

点击「🎬 生成一键脚本」开始…
Edge TTS 免费 零 API Key ffmpeg 合成 中文不乱码 本机一键运行

使用说明

本页面是纯前端，GLUCK 部署在 GitHub Pages 无后端，所以点按钮不是"立即出片"，而是生成可在本机一键运行的 Python 脚本，调用本机 OpenMontage + ffmpeg 渲染。全程零成本、零密钥。画面烧录固定品牌标题字幕；如需烧录完整文案字幕，请参考 中文视频示例 的 drawtext 逐段方案。
