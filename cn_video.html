能力说明

本成片由 OpenMontage（开源自动视频剪辑系统）在本机生成：文案经 微软 Edge TTS 免费合成中文配音（女声 Xiaoxiao / 男声 Yunxi，无需密钥），再经 ffmpeg 合成竖屏视频并烧录中文字幕。 全程 零成本，仅渲染时需联网走微软端点。素材来自公共领域 / AI 生成，合规可发。 中文文本在 OpenMontage 内会自动路由到 Edge TTS（tts_selector 强制优先）。

本地生成步骤

# 1. 安装中文配音引擎（一次性）
cd OpenMontage
.venv/Scripts/pip install edge-tts

# 2. 生成中文配音（text 换成你的选题文案）
python - <<'PY'
from tools.tool_registry import registry
registry.discover()
t = registry.get('tts_selector')
r = t.execute({'text':'在这里粘贴你的短视频文案',
               'voice':'zh-CN-XiaoxiaoNeural',
               'output_path':'projects/demos/voice.mp3'})
print(r.data)
PY

# 3. ffmpeg 合成竖屏视频 + 中文字幕（.srt 自行按句切分）
ffmpeg -y -f lavfi -i "gradients=s=1080x1920:c0=0x0E1326:c1=0x223D6B:c2=0x0B1020:x0=0:y0=0:x1=1080:y1=1920:d=27" \
  -i projects/demos/voice.mp3 \
  -vf "drawtext=fontfile='C\:\\Windows\\Fonts\\simhei.ttf':text='标题':fontcolor=white:fontsize=64:x=(w-text_w)/2:y=130,subtitles='projects/demos/voice.srt':charenc=UTF-8:force_style='FontName=SimHei,FontSize=50,PrimaryColour=&HFFFFFF,Outline=3,Bold=1,Alignment=2,MarginV=220'" \
  -c:v libx264 -pix_fmt yuv420p -c:a aac -shortest projects/demos/cn_video.mp4

完整脚本见 OpenMontage 仓库根目录 render_zh.sh。中文文本会自动路由到 Edge TTS，无需手动指定。
